## 它解决什么问题

有时候不是不会聊，是那句最合适的话总在洗澡的时候才想起来。

这个工具不替你说话，也不替你发送。它只是把你**想说的那句**，在你按下发送之前，写得更得体一点。

- 对方一句「你今天说话怎么怪怪的」，你不知道该解释、该撒娇、还是该装傻
- 想约人又怕太急，删了又打，最后只发出去一个「哦」
- 群里一句话接不上，话题就沉底了

它做的事情很简单：**看清这段对话里发生了什么，然后给你三条不同分寸的说法，你挑一条。**

## 功能

| 功能 | 说明 |
| --- | --- |
| **整段框选** | 框住一整段对话（不是只能框一句）。会自动区分谁说了什么，连上下文一起理解 |
| **三条回复** | 自然日常 / 情绪回应 / 人设风格，三种分寸，点一条直接填进输入框 |
| **人设书** | 自己写「这次我以什么身份说话」——温柔、损友、高冷、任何设定。人设书优先级高于预设人设 |
| **7 家模型** | DeepSeek / GPT / Claude / Gemini / Kimi / Qwen / GLM，填自己的 Key，用自己的额度 |
| **悬浮面板** | 可拖动、可调透明度（35%–100%）、可缩放（0.8–1.4 倍），位置和大小会记住 |
| **悬浮输入框** | 直接在聊天界面上输入 / 粘贴文字，不用切回 App |
| **手动输入** | 不想截图？把聊天记录复制粘贴进来也一样能用 |
| **历史记录** | 生成过的内容保存在本机，可随时清除 |

### 它不会做什么

- ❌ 不会替你发送消息 —— 只填进输入框，发不发你自己按
- ❌ 不会上传你的聊天截图 —— 裁剪和识别全在本机
- ❌ 不会记录你的对话到云端 —— 没有账号系统，没有服务器
- ❌ 不会内置 API Key —— 用你自己的，账自己算得清

## 下载安装

### 直接下载

到 [Releases](../../releases) 页面下载最新的 `AI沟通助手-vX.X.X.apk`。

### 安装步骤

1. 下载 APK 到手机
2. 点击安装，如果提示「未知来源」，按提示允许本次安装
3. 打开 App，按引导完成两步授权：
   - **悬浮窗权限**（显示在其他应用上层）
   - **屏幕录制权限**（用于框选截图，只截一帧，不录制）

> 系统要求：**Android 8.0（API 26）及以上**

### 可选：自动填入输入框

想让「点一条就自动填进输入框」生效，需要在系统设置里开启本应用的无障碍服务：

`设置 → 无障碍 → 已下载的服务 → AI 沟通助手 → 开启`

不开也能用 —— 会退化成「复制到剪贴板」，手动粘贴即可。

## 第一次使用

1. **填 API Key**
   进入 `设置 → 模型服务`，选一家（推荐 DeepSeek，便宜且中文好），点进去填 Key。
   - DeepSeek：[platform.deepseek.com](https://platform.deepseek.com/api_keys)
   - 其他服务商的 Key 在各自开放平台申请

2. **选人设**（可选）
   `人设` 页有内置预设（自然 / 温柔 / 成熟 等）。想更贴合自己，用**人设书**写一段"我是谁、我怎么说话"。

3. **开始用**
   打开微信 / QQ，点悬浮球 → **框选屏幕** → 框住你想回应的那段话 → 等三秒 → 点一条回复。

## 隐私与安全

| 环节 | 在哪里处理 |
| --- | --- |
| 截图裁剪 | 你的手机，本地 |
| 文字识别（OCR） | 你的手机，本地（ML Kit 中文模型，随 APK 打包） |
| 对话理解 / 生成回复 | 你选的模型服务商（只有你点「生成」时才发） |
| API Key | Android Keystore 加密，只存在本机，不进日志 |
| 生成历史 | 本机数据库，可随时清除 |

- 没有账号系统，不需要注册
- 没有埋点统计，没有第三方 SDK 上报
- 没有服务器，开发者看不到你的任何数据

**唯一离开设备的东西**：你点「生成」时，那段必要的对话文字会发给你自己配置的模型 API。

## 常见问题

**Q：完全免费吗？有没有会员？**
A：完全免费。没有内测码、没有会员、没有收费版。唯一成本是你自己的模型 API Key（DeepSeek 几块钱能聊很久）。

**Q：会不会偷偷把我的聊天发出去？**
A：不会。截图在本地处理完就丢弃，不上传。只有你点「生成」那一瞬间，才把文字发给你自己填的那家模型。

**Q：能自动帮我发消息吗？**
A：永远不会。它只把文字填进输入框，发送键必须你自己按。

**Q：支持 iPhone 吗？**
A：目前只有 Android。iOS 的悬浮窗限制太多，暂时没有计划。

**Q：为什么框选后要等几秒？**
A：本地 OCR + 模型生成需要时间，通常在 2–5 秒。可以在设置里调超时时间。

**Q：识别出的人设标签/说话人不对怎么办？**
A：截图里我的消息靠右、对方靠左，工具按气泡位置判断。如果某个 App 布局特殊，可以手动输入聊天记录来绕过。

**Q：会不会被平台封号？**
A：本工具不修改、不注入、不自动发送任何平台数据，只做截图识别和文本填入，行为等价于你自己打字。但请遵守各平台用户协议。

## 技术栈

- **语言**：Kotlin 2.0
- **UI**：Jetpack Compose + Material 3，单 Activity
- **架构**：MVVM + Repository，手动依赖注入
- **存储**：Room（对话历史 / 人设 / 人设书）+ DataStore（设置）
- **安全**：Android Keystore AES-256-GCM 加密 API Key
- **网络**：OkHttp + kotlinx.serialization，兼容三种协议
  - OpenAI 兼容（`/chat/completions`）
  - Anthropic Claude（`/messages`）
  - Google Gemini（`:generateContent`）
- **OCR**：ML Kit 中文文字识别（bundled，离线可用）
- **系统能力**：
  - MediaProjection 单帧截图（前台服务）
  - `TYPE_APPLICATION_OVERLAY` 悬浮窗（前台服务）
  - 无障碍服务（可选，用于填入文本）

## 源码

本仓库包含完整源码，可以直接用 Android Studio 打开构建。

```
app/src/main/java/com/aisocial/copilot/
├── ai/         模型调用（三种协议）、提示词拼装、回复解析
├── capture/    MediaProjection 单帧截图
├── core/       图片裁剪、OCR 文本清洗
├── data/       Room 数据库、DataStore 设置、Keystore 加密
├── domain/     领域模型与内置预设
├── ocr/        ML Kit 中文识别 + 说话人标注
├── overlay/    悬浮球 / 结果面板 / 悬浮输入框 / 无障碍填入
└── ui/         Compose 界面
```

构建需要：JDK 21、Android SDK 35。`local.properties` 里的 SDK 路径请自行配置（该文件不入库）。

> 目前没有做「一键构建」的 CI，需要本地编译。如果你只想要现成的安装包，去 [Releases](../../releases) 下载即可。
