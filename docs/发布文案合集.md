```markdown
## 这是什么

AI 沟通助手第一个公开版本。完全免费，直接下载安装即可。

## 下载

| 文件 | 说明 |
| --- | --- |
| `AI沟通助手-v1.2.3.apk` | 正式包，直接安装（Android 8.0+） |

安装时如果提示"未知来源"，到系统设置里允许本次安装即可。

## 这个版本有什么

- **整段框选**：框住一整段对话，自动分清谁说了什么，连上下文一起理解
- **三条回复**：自然日常 / 情绪回应 / 人设风格
- **人设书**：自定义"这次以什么身份说话"，人设书优先级高于预设人设
- **7 家模型**：DeepSeek / GPT / Claude / Gemini / Kimi / Qwen / GLM，填自己的 Key
- **悬浮面板**：可拖动、可调透明度（35%–100%）、可缩放（0.8–1.4 倍）
- **悬浮输入框**：直接在聊天界面上输入文字，不用切回 App
- **收起面板**：误触悬浮球后一键缩回，不用被迫关闭

## 已知问题

- 同一气泡内自动换行的多行文字，如果续行恰好居中，可能被标成系统提示（模型会按上下文兜底）
- 人设书与预设人设同时存在时，暂不支持"仅参考不覆盖"
- 仅支持 Android，暂无 iOS 版

## 隐私

- 截图裁剪与 OCR 全部本地完成，不上传
- API Key 用 Android Keystore 加密存储，不写日志
- 不自动发送，无云端账号，无统计埋点
```
