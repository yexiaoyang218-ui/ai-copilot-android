## 路线 A：给我一个 Token，我全程代做（推荐）

### 你要做的（约 2 分钟）

1. 打开 https://github.com/settings/tokens?type=beta
2. 点 **Generate new token**
3. 填：
   - **Token name**：`dsh-upload`
   - **Expiration**：**7 days**（用完就过期，安全）
   - **Repository access**：选 **Only select repositories** → 之后随便选一个（或者先选 All）
   - **Permissions** → Repository permissions：
     - **Contents**：`Read and write`（必需，传文件）
     - **Administration**：`Read and write`（可选，用来建仓库）
     - **Metadata**：`Read-only`（自动勾上）
4. 点 **Generate token**，复制那串 `github_pat_...`

### 然后把 Token 发我

我会做完这些：

- 创建仓库 `ai-copilot-android`
- 写入 `README.md`、`LICENSE`、`PRIVACY.md`、`发布文案合集.md`
- 创建 Release `v1.2.3`，把 APK 作为附件上传
- 设置仓库 Topics、Description
- 告诉你最终链接

### 用完记得撤销

https://github.com/settings/tokens → 删掉那个 token。
**别把 token 写进任何文件或截图里。**

> ⚠️ 安全提醒：token 等于你账号在那个权限范围内的钥匙。给它 7 天有效期，用完立刻删。

## 路线 B：你自己在网页上做（不用给我 token）

### 第一步：建仓库

1. 打开 https://github.com/new
2. **Repository name**：`ai-copilot-android`
3. **Description**：粘贴「发布文案合集.md」里的仓库简介
4. 选 **Public**
5. **不要**勾 Add a README（我们要自己传）
6. 点 **Create repository**

### 第二步：传文件

1. 在新仓库页面点 **uploading an existing file**
2. 把 `AI沟通助手-GitHub发布包\` 里的这些**拖进去**：
   - `README.md`
   - `发布文案合集.md`
   - （apk 先不要传到这里，走 Release 更合适）
3. 下面 **Commit changes** 点绿色按钮

### 第三步：加 LICENSE 和隐私政策

在仓库页点 **Add file → Create new file**：

- 文件名填 `LICENSE` → 粘贴「发布文案合集.md」里的 LICENSE 内容
- 文件名填 `PRIVACY.md` → 按「隐私政策要点」那 7 条展开写

### 第四步：发 Release（关键，下载地址在这里）

1. 仓库右侧点 **Releases** → **Create a new release**
2. **Choose a tag** 输入 `v1.2.3` → 点 “Create new tag”
3. **Release title**：粘贴「发布文案合集.md」里的 Release 标题
4. **Describe this release**：粘贴 Release 说明
5. 下面 **Attach binaries** 区域，把 `apk\AI沟通助手-v1.2.3.apk` 拖进去
6. 点 **Publish release**

发布后下载地址是：

```
https://github.com/你的用户名/ai-copilot-android/releases/download/v1.2.3/AI沟通助手-v1.2.3.apk
```

**把这个地址填进 B 站视频简介和置顶评论。**

### 第五步：补 Topics 和简介

仓库首页右上角 **⚙️（About）→ Edit**：

- Description 填上
- Topics 填：`android kotlin ai chat assistant ocr`
- 勾选 **Releases**、**Packages** 可选

## 关于包名和签名（重要）

当前 APK 是 **release 构建 + debug 签名**：

| 项 | 状态 |
| --- | --- |
| `debuggable` | `false` ✅ 不可调试，安全 |
| 签名 | debug keystore ⚠️ |
| 包名 | `com.aisocial.copilot` |

**这意味着什么：**

- ✅ 可以正常安装、正常用，对普通用户没区别
- ⚠️ debug 签名是公开的通用证书，任何人都能用它签一个同名包覆盖安装
- ⚠️ 将来如果上架应用商店，必须换成你自己的正式签名

**如果你只是发视频让网友自己装，现在这个够用。**

想更稳妥的话我可以帮你：

1. 生成一个**你自己的正式 keystore**（密码你保管）
2. 改用正式签名重新打包
3. 这样以后升级能保证是同一个开发者

要的话跟我说一声，我出脚本和步骤。
